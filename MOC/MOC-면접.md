## Anki로 내보내기

- 덱 계층 **최대 2단계** (`백엔드::Java`, `백엔드::분산`)
- 카드는 **원자적으로** — 카드 하나 = 사실 하나
- frontmatter `anki: true`인 페이지만 내보낸다
- **3분 버전은 카드로 만들지 않는다.** 카드는 30초 버전에서만 뽑는다

```dataview
TABLE level, anki
FROM "pages/questions"
WHERE anki = false
SORT level ASC
```
