## 무언가 하고 싶을 때

| 하고 싶은 것 | 어떻게 |
|---|---|
| 새 자료를 넣기 | `raw/inbox/`에 넣고 **"이거 ingest 해줘"** |
| 질문하기 | 그냥 물어본다. 답이 좋으면 `pages/syntheses/`로 파일링 요청 |
| 위키 건강검진 | **"린트 돌려줘"** → [[lint-체크리스트]] |
| 규칙 바꾸기 | [[CLAUDE]]를 같이 고친다. `log.md`에 `schema` 항목으로 남긴다 |

## 세 축이 만나는 곳

개념 ↔ 실험 ↔ 실무. **셋 중 둘 이상 연결된 개념만 면접에서 실제로 쓸 수 있다.**

```
   [[조건부 상태 전이 선점]]  ← 개념
            │
   ┌────────┼────────┐
   ▼                 ▼
[[선착순 쿠폰 발급 동시성]]   pages/private/ (비공개 판단 기록)
      실험                        실무
```

이 삼각형이 안 만들어지는 개념은 아직 안 익은 것이다. Lint에서 이걸 본다.
