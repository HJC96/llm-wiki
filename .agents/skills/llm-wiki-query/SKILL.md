# LLM Wiki Query

## 공통 준비

이 스킬은 LLM Wiki 저장소 전용이다. 작업 디렉터리에서 위로 올라가 `CLAUDE.md`, `index.md`, `pages/`가 함께 있는 볼트 루트를 확인한다. `AGENTS.md`의 Codex 대응 규칙과 `CLAUDE.md`를 읽고 해당 작업에 필요한 템플릿·태그 사전을 사용한다. 명령은 볼트 루트에서 실행한다. 다른 볼트라면 `--vault <볼트>`를 하위 명령 앞에 둔다.

일반 ChatGPT에서 이 문서를 참고하는 경우 `LLM-WIKI-GUIDE.md`의 업로드 모드 지침을 함께 따른다. 실제 파일·실행 도구가 없으면 명령을 실행했다고 보고하지 않는다.

## 답변

1. `index.md`에서 주제를 찾고 관련 MOC·페이지로 내려간다. 검색은 `rg`로 제목·동의어를 함께 확인한다. 필요할 때만 원본 `raw/`를 읽는다.
2. 지난주·최근 학습 질문은 `log.md`의 해당 기간과 출처를 확인한다. 파일의 `updated`만으로 실제 공부한 날짜를 단정하지 않는다.
3. 주장마다 실제 읽은 `[[출처 페이지]]`를 인용한다. Codex 채팅에서는 클릭 가능한 절대 파일 경로도 제공한다. 문서 본문에서는 Obsidian 위키링크를 유지한다.
4. 근거가 없으면 그 범위에서 없다고 말하고 필요한 자료를 제안한다. 불확실한 추론, 출처 간 충돌, 확인된 사실을 구분한다. 사용자가 외부 조사를 요청한 경우 그 근거를 위키와 분리한다.
5. 질문에 맞춰 짧은 설명·비교표·Mermaid 등을 쓴다. 대안·적용 조건·트레이드오프를 함께 설명한다. 저장 요청이 없으면 답변하며 필요한 경우 파일링을 제안한다.

## 답 저장

`저장`, `파일링`, `면접 답으로 남겨줘`처럼 요청받았으면 다시 승인받지 않고 수행한다. 기존 유사 페이지를 확인하여 보강하거나 다음 템플릿을 따른다.

- 종합: `meta/templates/synthesis.md` → `pages/syntheses/`. 질문, 짧은 답, 근거, 확신도, 이 답이 바뀔 조건, 연결.
- 면접: `meta/templates/question.md` → `pages/questions/`. 한 질문, 30초 답, 3분 답, 꼬리질문, 근거. `anki`, `level`을 기록한다.

출처·관련 MOC·`index.md`를 함께 갱신하고 `log.md` 끝에 `## [YYYY-MM-DD] query | 질문 요약`을 남긴다. 대화에서 나온 판단이나 경험은 `source: 대화 (YYYY-MM-DD)`로 구분한다. 공개 영역에 사내 식별 정보를 쓰지 않는다. MOC 양방향 연결을 점검한다.
